## 📌 Project Overview

SIM Swap fraud occurs when criminals trick telecom providers into transferring a victim's phone number to a new SIM card. This application simulates a telecom provider's monitoring system that evaluates incoming SIM swap requests using a rule-based engine, flags high-risk activities, generates security alerts, and tracks fraud incidents.
